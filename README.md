
## Project Improvements

This project provides a simple Bash-based calculator for computing simple interest.

### Features
- Accepts principal amount, annual interest rate, and time.
- Calculates simple interest using the standard formula.
- Validates numeric inputs.
- Displays the calculated interest in a readable format.

### Future Improvements
- Add compound interest calculation.
- Improve input validation and error handling.
- Add automated tests.

## How to Run

1. Open a terminal.
2. Navigate to the project directory.
3. Run `bash simple-interest.sh`.
4. Enter the principal amount, annual interest rate, and time when prompted.
